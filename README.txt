MIAZI PERSONAL HISAB — OFFLINE + ONLINE

Included:
- index.html: app
- supabase_setup.sql: database setup for the NEW Supabase project
- manifest.webmanifest + sw.js + icons: installable PWA/offline shell

IMPORTANT:
1. Open Supabase SQL Editor in project hpcrvxqklgjegrchfdhh and run supabase_setup.sql.
2. Deploy the whole folder to a HTTPS host (GitHub Pages is suitable).
3. Open the live site once while online, then use browser menu > Install app / Add to Home screen.
4. Create an account with email/password inside the app. Log in on other devices with the same account.
5. Entries are saved locally first. When online and logged in, the app syncs with Supabase.
6. Keep regular JSON backups. Clearing browser/app data can remove local-only entries that have not synced.

The publishable key is intended for client-side use. Never add a Supabase secret/service_role key or database password to this app.
